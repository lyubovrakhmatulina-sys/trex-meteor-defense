# T-Rex Meteor Defense

A lightweight, mobile-first arcade game built with plain HTML, CSS, and JavaScript.

## Run

Open `index.html` in a modern browser. No install, build step, account, or server is required.

## Play

Tap falling meteors to protect the T-Rex. Small, medium, and large meteors are worth 10, 20, and 30 points. Keep a streak to build a combo; every fourth consecutive hit doubles points. Three meteors reaching the dinosaur end the round. Your best score is saved in the browser on this device.

The game scales to phone and tablet screens, supports pointer/touch input, and includes a sound toggle. Sound is synthesized in the browser and begins after the first user interaction.
